# TC-014

| Campo | Contenido |
|---|---|
| **Identificador** | TC-014 |
| **Requisitos cubiertos** | Construcción reproducible desde un clon limpio (condición del tag `v0.1.0`, ver [cronograma](../../project-management/CRONOGRAMA.md)). RF/RNF: por asignar (ver [matriz](../verification-plan/matriz-trazabilidad.md)) |
| **Objetivo** | Comprobar que alguien ajeno al equipo puede clonar el repositorio y construirlo siguiendo solo la sección «Construcción» del README. |

## Precondiciones
1. Linux (Ubuntu 22.04 / 24.04) o WSL2 con Python 3.10 o superior y `git`.
2. Una carpeta vacía; ningún archivo previo del proyecto.
3. Acceso a `https://github.com/deniele04/JobRunner.git`.

## Pasos
| # | Acción |
|---|---|
| 1 | Verificar la versión de Python: `python3 --version` (3.10 o superior). |
| 2 | Clonar: `git clone https://github.com/deniele04/JobRunner.git && cd JobRunner`. |
| 3 | Preparar el proyecto: `./scripts/setup.sh`. |
| 4 | Comprobar el código de salida del paso 3 y el mensaje impreso. |

`verif/scripts/verify.sh` automatiza los pasos 2 a 4 clonando el repositorio local (último commit) en una carpeta temporal.

## Resultado esperado
- El clon se completa sin errores.
- `./scripts/setup.sh` termina con código 0 e imprime `Construcción OK` con la versión de Python, sin instalar dependencias.

## Resultado observado
Ejecución `20261002-avance1` (Python 3.13.16, Linux): `verify.sh` clonó el repositorio en una carpeta temporal y `./scripts/setup.sh` terminó con código 0 e imprimió `Construcción OK: Python 3.13.16, sin dependencias externas.`

Alcance: la ejecución automatizada clona el repositorio local, no la URL de GitHub. Antes del tag `v0.1.0`, repetir los pasos 1 a 4 a mano con la URL real desde un entorno distinto al de desarrollo.
