# JobRunner
## Propósito
RoyiRunner es es un sistema diseñado para entornos Linux capaz de ejecutar, administrar, observar y controlar trabajos en segundo plano. Esta implementación establecerá la identidad, responsabilidades y forma de trabajo inicial de nuestro equipo como proveedor del sistema.
